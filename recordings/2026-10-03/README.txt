PhysicsCursor demo — recorded with OBS Studio

PhysicsCursor-demo.mp4: a short English demo featuring Nautilus, VS Code, text selection in the PhysicsCursor repository in Zen, followed by the canvas with a system-cursor comparison and enlarged transition detail.

The mouse cursor and its physics/transitions are captured from the real Hyprland session. Input uses a Wayland virtual pointer. The system reference disables the dynamic-cursors plugin effects. The canvas comparison repeats the same trajectory.

H.264, 1280x720, 30 fps, no audio. The slow-motion close-up repeats original frames at 4x slower speed; no generated interpolation. Some capture frames were delayed by the available hardware.

Separate short takes are in takes/. Original cursor settings restored. OBS used a temporary configuration; the original profile was preserved. VS Code used temporary preferences in English. No project source files were edited.
